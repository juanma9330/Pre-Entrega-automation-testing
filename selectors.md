#Selectors de proyecto talento tech

## login page
- input usuario: #user-name (id campo de texto usuario) 
- input contraseña: #password (id campo de texto contraseña) 
- input boton login: #login-button (id del campo de entrada tipo submit)
- mensaje de error: [data-test="error"] - .error-message-container h3 (mensaje de error)

## Inventario
- titulo de pagina: .title (class texto titulo) 
- nombre de productos: .inventory_item_name (class del nombre de los productos)
- boton menu hamburguesa: #react-burger-menu-btn (id del menu hamburguesa)
- filtro de productos: .product_sort_container (class del fitro de productos)

## Carrito
- boton add to cart: .btn_inventory (class en comun de los botones para agregar productos al carrito)
- contador carrito: .shopping_cart_badge (clase del numero contador de productos en carrito)
- nombre producto: .inventory_item_name (clase del nombre de productos en general en inventario y en carrito)
- boton carrito: .shopping_cart_link (clase del boton para entrar al carrito)
